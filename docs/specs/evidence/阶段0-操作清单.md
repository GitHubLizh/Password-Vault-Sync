# 阶段 0 操作清单：谁做什么

对应 `docs/specs/2026-10-01-多设备同步.md` 故事 1–6、ADR 0022、ADR 0012。命令全部在 2026-10-01 用 `npx wrangler@4`（4.144.0，本仓库实测装得上）跑过 `--help` 或 `--dry-run` 核实过存在与写法。

**开始前的两个环境提醒**

- 你这台开发机推 GitHub 走 `127.0.0.1:29290` 代理。`wrangler login` / `deploy` 同样要出公网，若卡住先 `export HTTPS_PROXY=http://127.0.0.1:29290` 再试。**副作用要知道**：带代理的桌面测出来的连通性不代表手机蜂窝网，这正是 ADR 0012 里"桌面结果不算数"的同一件事。
- `wrangler login` 会开浏览器做 OAuth 并回调本机端口，属于一次性授权；完成后用 `npx wrangler whoami` 确认账号与 Account ID。

## 我这边已经做完并验证过的

| 东西 | 状态 |
|---|---|
| `scripts/sync-fake-bucket.mjs` 本地假桶 | 真 HTTP 复刻 `If-None-Match: *`→412、`If-Match` 不符→412、对象缺失→404、成功写→200 带新 ETag、GET 回原字节 |
| `scripts/sync-carrier-probe.mjs` 载体闭环 | 对着假桶**跑通 11 步全绿**（含两个 412 分支、并发拒写、合流后再推、删后 404），退出码 0 |
| SigV4 自签 | 用 `node:crypto` 的 `createHash/createHmac` 实现，未引第三方依赖；**签名能否被 R2 接受是未验证的**，只有真桶能证 |
| `worker/index.mjs` 只读代理骨架 | 在 Node 里用 mock 绑定跑过六种情形：`/ping` 200、命中对象 200 并转发 `httpEtag`、对象缺失 404（`NO_CLOUD_COPY`）、非 GET 405（只读）、未知路径 404、未绑桶 501。**故意不设 `access-control-allow-origin`**——只读页与代理同源，通配 ACAO 等于白送"任何网页都能替你拉一次密文"的开孔 |
| `worker/wrangler.toml` | `npx wrangler deploy --dry-run -c worker/wrangler.toml` 通过：打包 2.14 KiB、No bindings found、不上传 |

## 只能你做的（需要 Cloudflare 账号）

1. **登录**：`npx wrangler login`（会开浏览器授权），完成后 `npx wrangler whoami` 确认，并把输出里的 **Account ID 记下来**——真桶 endpoint 要用它拼。
2. **建桶**：`npx wrangler r2 bucket create <桶名>`。想测 r2.dev 那一类域名再加一句：`npx wrangler r2 bucket dev-url enable <桶名>`，然后用 `... dev-url get <桶名>` 拿到那条 URL。
3. **拿 Access Key（AK/SK）**——wrangler 4.144.0 的 `r2` 子命令下只有 `object / bucket / sql`，**没有创建凭证的命令**，只能在控制台做。入口（2026-10-01 官方文档核实）：**R2 object storage → Account Details → 在 "API Tokens" 那一行点 "Manage" → Create Account API token**（或 User API token）。权限策略四选一：`Admin Read & Write` / `Admin Read only` / `Object Read & Write` / `Object Read only`，并且**可以把 token 限定到具体桶**。请选 **Object Read & Write + 只授权你那一个桶**，不要用 Admin；文档写明这类凭证"在手动吊销或到达预设日期前一直有效"，**所以务必设一个过期日期**。注意页面上显示的仍是长期 `Access Key ID + Secret Access Key` 这一对，它不是短期 STS 凭证。
4. **部署 Worker**：`npx wrangler deploy -c worker/wrangler.toml`，然后 `npx wrangler r2 bucket list` 之外再记下 Worker 的 `*.workers.dev` 地址。
5. **真桶闭环**（把上一步的东西填进去）：
   ```
   node scripts/sync-carrier-probe.mjs \
     --endpoint https://<ACCOUNT_ID>.r2.cloudflarestorage.com \
     --bucket <桶名> --access-key-id <AK> --secret-access-key <SK> --region auto
   ```
   期望 11 步全绿。任何一步与预期不符，**把整段输出原样贴回来**（脚本会打印状态码、ETag 形态、参与签名的头），那就是我们要记进 ADR 0012 的实测事实。特别注意第①步：如果这里出现 `SignatureDoesNotMatch`，八成是 path-style URI 或 `region=auto` 的规范化写法与我的实现不一致，而不是脚本语义错了。
6. **手机第 2 轮可达性**：把 `https://<你的 Worker>.workers.dev/ping`（以及 `https://<桶>.r2.dev/...`，若第 2 步开了）填进探针页新增的"自填地址"框，**关掉 WiFi、不开代理**，在手机上跑一次；顺便**换一个浏览器**再跑一次（第 1 轮是华为浏览器 ArkWeb，它自带的网页保护通道可能是混杂因素）。另外地址栏直接访问 `https://1.1.1.1/cdn-cgi/trace`，看是否出现 `colo=` 行——这一条能把"IP 直连被拦"和"浏览器拦 fetch"分开。

## 回传什么

阶段 0 的判据是"有结论"，不是"全绿"。请把三样东西发回来，我据此写 `docs/specs/evidence/2026-10-01-载体实测-第2轮.md` 并决定 ADR 0012 是转 accepted 还是作废：

- 真桶闭环脚本的完整输出（11 行结果 + 末尾两行）
- `wrangler whoami` 的 Account ID 一行（**不要**贴 AK/SK，凭证不进仓库、不进聊天记录）
- 手机第 2 轮探针页结果框的整段文字，两个浏览器各一份

## 顺手核实到的成本量级（spec 7.4"配额与成本上限"未决项的第一手材料）

R2 pricing 页（2026-10-01）写明：**出网流量免费**（"Egress (data transfer to Internet) | Free"）、存储有 **10 GB-month** 的免费量、写类与读类操作各有每月免费额度，且 `DeleteObject`、`DeleteBucket`、`AbortMultipartUpload` 属免费操作。**但两项操作额度的归属我没有可靠确认**——抓到的摘要给的是 Class A 100 万 / Class B 1000 万，而我按 S3 惯例的预期恰好相反（Class A 是写、量小更合理），两者对不上时以 pricing 页原表为准，不要引用这里。

对我们的量级判断不受这个歧义影响：一个档一份 ≤ 8 MiB 快照，写发生在保存后 debounce 与锁定时、读发生在解锁与手动同步，个人多设备的月请求量与免费额度差几个数量级。真桶闭环脚本跑通后，我会把"每步属于哪一类请求"标进证据文件，届时这条未决项可以正式关掉。

## 还没解决的一件事

`--region auto` 与 path-style（`/<bucket>/<key>`）是按 R2 的 S3 兼容文档写的，**我没能从文档里确认桶名放进 URL 路径这一段的确切写法**（那页只给了 `https://<ACCOUNT_ID>.r2.cloudflarestorage.com` 这个端点形式）。脚本把 `--endpoint / --bucket / --region / --service` 都做成了参数，所以真桶上一旦报鉴权或寻址错误，可以先只换参数试，不必改代码。
